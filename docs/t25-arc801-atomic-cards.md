Parent unit: **ARC801 — Algebra, Functions & Proof Language**

ARC801 is a prerequisite/readiness unit. It is not one SPIRE mission. Its role is to remove algebraic, functional and logical ambiguity before later M.Stat work.

The legacy parent-readiness plan expected independent evidence for these four ownership targets, followed by a mixed readiness check. Child clearance alone does not automatically clear the parent:

1. `T25-ARC801-A01` — Domain-Safe Algebra
2. `T25-ARC801-A02` — Equations & Inequalities as Solution Sets
3. `T25-ARC801-A03` — Functions, Changed Inputs & Parameters
4. `T25-ARC801-A04` — Mathematical Claims, Quantifiers & Counterexamples

No fixed time quota is required. A card can clear rapidly through an independent diagnostic if the learner already owns it. Failure should trigger targeted repair of the failed concept, not repetition of the entire parent unit.

The legacy four contracts are retained in `js/data/t25-atomic-arcs-001-025.js`. The active `js/data/t25-atomic-arcs.js` registry now exports the audited 162-session route.

## How to use these cards

Do **not** paste the entire ARC801 deck into one live SPIRE session.

Use one atomic card at a time:

`T25 parent unit → one atomic card → T25-aware Mission Compiler → Sealed Mission → SPIRE Master + Guardian → archive`.

For ARC801, begin with `T25-ARC801-A01`.

Because ARC801 is mostly prerequisite infrastructure, use a short independent diagnostic before creating a long sealed mission. If the learner already demonstrates ownership, record that evidence and continue. Use SPIRE only where a genuine conceptual obstacle remains.

## Parent completion gate

After the four cards are individually supported, use one mixed readiness check containing unfamiliar tasks that require:

- legal algebra with correct domain tracking;
- correct equation/inequality solution-set reasoning;
- correct changed-input and parameter interpretation;
- correct interpretation of an elementary quantified or implicational claim;
- appropriate use of a witness or counterexample.

The final check tests readiness, not speed.

A later clerical slip or conceptual failure does not automatically reopen historical clearance. Record a separate retention/repair recommendation. Any substantive recovery workflow must be explicit and preserve the original evidence.

Once ARC801 is clear, stop. Do not add extra formal logic, algebra tricks, proof techniques or enrichment merely because they may later be useful.

## Downstream handoff

ARC801 licenses the elementary symbolic and logical language assumed by later T25 units, especially:

- ARC802 — Sets, Relations & Functions;
- ARC803 — Polynomials & Theory of Equations;
- later calculus work using changed-input notation;
- probability and statistics work using assumptions, parameters, quantifiers and counterexamples.

Previously earned material remains earned and need not be rediscovered merely because a later problem uses it.
