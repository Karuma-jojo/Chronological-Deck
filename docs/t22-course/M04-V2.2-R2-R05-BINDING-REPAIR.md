## Binding mechanism

`docs/t22-course/audit/m04-candidate-math-bindings.mjs` contains explicit readers
for the ten fixed public problems. This is not a general natural-language parser.
An unrecognized or incomplete mathematical role fails validation rather than
silently falling back to detached oracle inputs.

For each covered assessment, the validator:

1. requires the expected assessment identity and oracle kind;
2. extracts inputs from the public prompt and checks probability legality;
3. compares any mathematical table against those public inputs;
4. requires the typed oracle inputs to equal the public model;
5. computes from the public inputs and compares the complete expected output;
6. parses role-specific reference/rubric values and compares them with computed
   results, including path masses, denominators, endpoint witnesses and padding;
7. retains the legacy token checks as additional guards, not as the numeric binding.

The exact ten-task coverage and complete oracle output shape are checked so
omitting a critical task or an output cannot silently remove its protection.
